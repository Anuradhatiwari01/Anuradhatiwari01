## 📌 Featured Projects

### 💬 [Real Time Chat Application](https://github.com/Anuradhatiwari01/real-time-chat-app)
Built a full-stack real-time chat web app using **Spring Boot WebSocket** and the **STOMP protocol**. Supports live message broadcasting between multiple users simultaneously. Designed a clean, responsive interface with Bootstrap and maintained a clear separation between frontend (JS/CSS) and backend.

`Spring Boot` `WebSocket` `STOMP` `JavaScript` `Bootstrap`

---

### 🤖 [Customer Purchase Prediction](https://github.com/Anuradhatiwari01/purchase-prediction-app)
End-to-end **ML web application** predicting customer purchase behavior using Logistic Regression. Built the complete pipeline — data preprocessing, feature scaling, model evaluation — and deployed a **Flask-based web interface** for real-time predictions on live data.

`Python` `Scikit-learn` `Logistic Regression` `Flask` `Pandas` `NumPy`

---

### ⚙️ [CALC Interpreter — Mini Scripting Engine](https://github.com/Anuradhatiwari01/calc-interpreter-java)
Built a **custom interpreter from scratch in pure Java** for a math-based scripting language. Implements a full three-stage pipeline: lexer → AST parser → executor. Handles variables, conditional statements, loops, and operator precedence automatically through tree-based evaluation.

`Java` `Interpreter Design` `AST` `Lexer` `Parser`

---

### 📊 [SortVision — Sorting Algorithm Visualizer](https://github.com/Anuradhatiwari01/sorting-visualiser-app)
Interactive web-based tool that visualizes **step-by-step execution of sorting algorithms**. Core algorithm logic written in Python generates intermediate sorting states, enabling clear frame-by-frame visualization of comparisons and swaps for intuitive understanding.

`Python` `JavaScript` `HTML` `CSS` `Algorithm Design`

---

### 🔗 [LinkedIn Network Analysis](https://github.com/Anuradhatiwari01/linkedin-network-analysis)
Analyzed a large LinkedIn student connection dataset to uncover **connectivity patterns and relationship distribution**. Identified highly connected users and modeled how connections form and scale within a social network using graph-based and statistical techniques.

`Python` `Pandas` `NumPy` `Matplotlib` `Network Analysis`
